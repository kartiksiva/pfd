## 3. General Observations & Guidance

### [LOW] Observation: Database Persistence in Docker
- **Note:** The current `docker-compose.yml` mounts the backend source code (`../backend:/app`), which includes the `pfcd.db` SQLite file. This provides persistence for the database as well. However, for a production-like setup, it is usually better to move the `.db` file to a dedicated `/data` volume to separate code from state. For the MVP, the current setup is acceptable and convenient.

### [LOW] Observation: Frontend Integration Tests
- **Note:** As you progress through Milestone 6, consider adding a basic "Playwright" or "Cypress" smoke test for the frontend to verify that the `POST /api/jobs` multipart upload and polling logic remain functional after UI changes.
